# TypoScript

Десктопное Windows-приложение для обнаружения **тайпосквоттинга** — анализирует введённый домен или URL и определяет, не является ли он подделкой под известный сайт.

## Что такое тайпосквоттинг

Тайпосквоттинг (typosquatting) — регистрация доменов, похожих на популярные сайты, с расчётом на опечатку пользователя или визуальное сходство символов. Примеры:

- `gooogle.com` вместо `google.com` (лишняя буква)
- `paypa1.com` вместо `paypal.com` (цифра 1 вместо l)
- `gооgle.com` вместо `google.com` (кириллические «о» вместо латинских)

## Возможности

- Ввод домена вручную или выбор из списка популярных доменов
- Извлечение хоста из полного URL (схема, путь, порт — отбрасываются)
- Нормализация визуально похожих символов: кириллица → латиница, `0` → `o`, `1` → `l`
- Расчёт расстояния Левенштейна до 25 популярных доменов
- Цветовой градиент результата: зелёный → жёлтый → красный
- Побуквенный diff с подсветкой отличий

## Как работает детектор

1. **Извлечение хоста** — из URL вырезается только доменная часть: убирается схема (`https://`), порт (`:443`), путь (`/page`), `www.`
2. **Нормализация гомоглифов** — все визуально похожие символы заменяются на стандартные латинские
3. **Точное совпадение** — если после нормализации домен совпал с популярным, но в оригинале была кириллица — это спуфинг
4. **Расстояние Левенштейна** — для каждого из 25 популярных доменов считается edit distance (сколько правок нужно, чтобы один домен превратить в другой)
5. **Скоринг** — за каждое близкое совпадение начисляется вес; если сумма ≥ 3 или есть совпадение с расстоянием 1 — домен подозрителен

### Веса по расстоянию Левенштейна

| Расстояние | Вес | Высокий риск |
|-----------|-----|--------------|
| 1 (1 правка) | 5 | да |
| 2 (2 правки) | 3 | нет |

### База популярных доменов (25 штук)

`google.com`, `youtube.com`, `facebook.com`, `instagram.com`, `twitter.com`, `x.com`, `microsoft.com`, `apple.com`, `amazon.com`, `netflix.com`, `paypal.com`, `github.com`, `wikipedia.org`, `linkedin.com`, `vk.com`, `mail.ru`, `yandex.ru`, `ok.ru`, `whatsapp.com`, `telegram.org`, `zoom.us`, `dropbox.com`, `adobe.com`, `ebay.com`, `bbc.co.uk`

## Примеры работы

| Ввод | Результат |
|------|----------|
| `google.com` | Не подозрительно (точное совпадение) |
| `gооgle.com` (кириллические о) | Подозрительно — алфавитный спуфинг |
| `gogle.com` | Подозрительно — расстояние 1 до google.com, вес 5 |
| `paypa1.com` | Подозрительно — цифра 1 → l, совпадение с paypal.com |
| `g00gle.com` | Подозрительно — 0 → o, совпадение с google.com |

## Требования

- Windows 10 / 11
- Visual Studio 2019 или 2022 (компонент «Разработка классических приложений на C++»)
- Windows SDK (устанавливается вместе с Visual Studio)

## Сборка

1. Открыть `TypoScript.slnx` в Visual Studio
2. Выбрать конфигурацию `Debug` или `Release`, платформу `x64`
3. `Build → Build Solution` (`Ctrl+Shift+B`)
4. Готовый `.exe` находится в `x64\Debug\` или `x64\Release\`

## Структура проекта

```
TypoScript/
├── TyposquatDetector.h/.cpp   — движок анализа (алгоритм, нормализация, Левенштейн)
├── TypoScriptDlg.h/.cpp       — главное окно (UI, отчёт, визуализация diff)
├── TypoScript.h/.cpp          — точка входа MFC-приложения
├── pch.h/.cpp                 — предкомпилированный заголовок
├── framework.h                — подключение MFC и Windows
├── resource.h / TypoScript.rc — ресурсы диалога (ID контролов, шаблон)
├── GUIDE.md                   — учебный разбор каждого слова в коде
└── README.md                  — этот файл
```

## Технологии

| Что | Зачем |
|-----|-------|
| C++20 | Язык разработки |

| Стандартная библиотека C++ | `std::vector`, `std::string`, `std::sort` |
